# VES — Vereda Editorial System

## Objetivo

O Vereda Editorial System reúne as decisões visuais e comportamentais que
mantêm o produto coerente, acessível e reconhecível.

O sistema nasce de uma ideia central:

> **O aplicativo deve desaparecer para que as obras apareçam.**

## Direção visual

A direção aprovada combina:

- Nordic Editorial;
- biblioteca contemporânea;
- modernidade limpa;
- tipografia editorial;
- acessibilidade como parte da estética.

O Vereda deve parecer moderno, intuitivo e clean. Não deve simular papel
antigo, biblioteca histórica ou estética religiosa.

## Pilares

### Clareza

O próximo passo é evidente.

### Calma

Nenhum elemento compete por atenção sem necessidade.

### Legibilidade

Texto, contraste e áreas de toque funcionam para diferentes idades e
capacidades visuais.

### Consistência

Tokens e componentes reutilizáveis substituem decisões isoladas.

### Permanência

Preferimos soluções atemporais a tendências passageiras.

## Princípios visuais

- branco quente, nunca amarelado;
- verde sage como orientação, não decoração;
- verde profundo para ações e contraste;
- tipografia serifada apenas em títulos e momentos editoriais;
- tipografia sans-serif para controles e informação funcional;
- espaço em branco generoso;
- sombras discretas;
- bordas suaves sem aparência infantil;
- uma ação dominante por tela;
- nenhum texto funcional abaixo de 14 px;
- áreas interativas com pelo menos 44 × 44 px, preferencialmente 52–56 px.
