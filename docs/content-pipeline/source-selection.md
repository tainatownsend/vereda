# Canonical source selection

## Selected reference collection

The five supplied files belong to the Federação Espírita Brasileira historical
edition collection.

They provide consistent:

- typography;
- page dimensions;
- table-of-contents formatting;
- chapter-opening treatment;
- page numbering;
- editorial hierarchy.

## Translation note

Four works use the Guillon Ribeiro translation.

`O Céu e o Inferno` uses the Manuel Justiniano Quintão translation, despite the
local filename containing the word `Guillon`.

## Technical assessment

The PDFs contain selectable text and do not require OCR.

Extraction still requires deterministic handling of:

- line-ending hyphenation;
- repeated headers and footers;
- page numbers;
- decorative chapter-opening pages;
- blank divider pages;
- footnotes and editorial notes;
- paragraph reconstruction;
- question-and-answer numbering.

## Rights assessment

Each supplied PDF states that reproduction requires authorization.

For this reason, these files are classified as:

```text
local-structural-analysis-only
```

They are not yet approved as the production text distributed by Vereda.

## Source-file policy

Source PDFs are never committed to Git.

The repository stores:

- bibliographic metadata;
- filename;
- SHA-256 checksum;
- inspection reports;
- parser code;
- approved non-infringing derived metadata.

Full extracted text remains outside version control until rights clearance and
the production-source strategy are approved.
